⚠️ Unit 18 - Imperatives

P2 English · 祈使句（香港小学二年级）

Sentences 句型
Giving Commands & Requests
📺 点击搜索 YouTube 教学视频 →
Open the door, please.
肯定祈使句：以动词原形开头
Sit down, please. / Stand up.
常见祈使用语：坐下、起立
Don't run in the hallway!
否定祈使句：Don't + 动词原形
Don't be late!
Don't + be + 形容词/名词
Please be quiet.
加 please 让祈使句更礼貌
📌 祈使句的主语通常是 You（隐含的），不说出来
📌 please 可以放在句首或句尾
📌 Don't 后面永远跟动词原形
📝 练习题 — 选择正确答案
