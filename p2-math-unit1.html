🔢 1000以內的數

P2 數學 · 認識千以內的數、數位、順序與規律（香港小學二年級）

數位觀念
📌 認識個位、十位、百位
一個三位數由百位、十位、個位組成：
📝 123 = 1個百 + 2個十 + 3個一
讀作：一百二十三
📝 506 = 5個百 + 0個十 + 6個一
讀作：五百零六（中間的零要讀出來）
📝 830 = 8個百 + 3個十 + 0個一
讀作：八百三十（末尾的零不讀）

讀寫
📌 用數字和文字表達
📝 204 → 二百零四
數字中的"0"要讀作"零"
📝 六百三十 → 630
末尾的十位是0不用寫出"零"
📝 九百零七 → 907
個位不是0，所以十位的0要寫出來
順序規律
📌 數數與規律
📝 一個一個數：980, 981, 982, ____, ____
答案：983, 984（每次+1）
📝 十個十個數：430, 440, 450, ____, ____
答案：460, 470（每次+10）
📝 一百個一百個數：200, 300, 400, ____, ____
答案：500, 600（每次+100）
