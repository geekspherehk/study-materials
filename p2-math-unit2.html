P2 數學 · 兩位數進位加法、退位減法、應用題（香港小學二年級）

進位加法
📌 兩位數加法（進位）
個位相加滿10，向十位進1：
📝 47 + 28 = ?
7+8=15（進1寫5），4+2+1=7 → 75
📝 56 + 37 = ?
6+7=13（進1寫3），5+3+1=9 → 93

退位減法
📌 兩位數減法（退位）
個位不夠減，向十位借1當10：
📝 62 - 28 = ?
2不夠減8，借1變12-8=4，十位5-2=3 → 34
📝 84 - 56 = ?
4不夠減6，借1變14-6=8，十位7-5=2 → 28
應用題
📌 加減應用題
📝 果籃裡有38個蘋果和25個橙，共有水果多少個？
38+25=63（個）
📝 錢包原有75元，買書用了48元，還剩多少元？
75-48=27（元）
