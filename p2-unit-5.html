👆 Unit 5 - this / that / these / those

P2 English · 指示代词（香港小学二年级）

Pronouns 代词
Demonstrative Pronouns
📺 点击搜索 YouTube 教学视频 →
This is my book. （近处）
this = 这个（近处单数）
That is a tree. （远处）
that = 那个（远处单数）
These are my pencils. （近处复数）
these = 这些（近处复数）
Those are stars. （远处复数）
those = 那些（远处复数）
📌 this/these 靠近，that/those 远离
📌 this/that 是单数，后面用 is；these/those 是复数，后面用 are
