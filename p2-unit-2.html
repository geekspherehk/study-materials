🔤 Unit 2 - a / an / the

P2 English · 冠词（香港小学二年级）

Articles 冠词
a / an / the
📺 点击搜索 YouTube 教学视频 →
a dog, a university, a hot day
a + 辅音音标开头的词
an apple, an egg, an old man
an + 元音音标开头的词（注意听发音，不是看字母）
an hour (h不发音), an honest boy
特殊情况：h 不发音时用 an
the sun, the book on the desk
the = 特指，双方都知道的事物
📌 a/an 是不定冠词，用于第一次提到的单数可数名词
📌 the 是定冠词，用于已提到或双方都知道的名词
📌 口诀：a dog, an apple, the is special
