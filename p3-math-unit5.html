🍕 分數（初步概念）

P3 數學 · 認識分數與同分母加減（香港小學三年級）

認識分數
📌 分數是什麼？
分數表示「將1個整體平均分成若干份，取其中的幾份」。分數由分子（在上）和分母（在下）組成。
📝 1/2 讀作「二分之一」
將一個薄餅平均分成2份，取其中1份
📝 3/4 讀作「四分之三」
將一個蛋糕平均分成4份，取其中3份
📝 5/8 分母=8, 分子=5
分母表示分成8份，分子表示取了5份

分數比較
📌 比較分數的大小
同分母的分數：分子越大，分數越大。同分子的分數：分母越大，分數越小。
📝 3/7 vs 5/7
分母相同（7），比較分子：5>3，所以 5/7 > 3/7
📝 1/3 vs 1/5
分子相同（1），分母越小分數越大：1/3 > 1/5
📝 把 2/9, 5/9, 7/9 從小到大排列
2/9 < 5/9 < 7/9（同分母，分子越小越小）
分數加減
📌 同分母分數的加法和減法
分母不變，分子相加或相減。
📝 2/7 + 3/7 = (2+3)/7 = 5/7
分母7不變，分子相加 2+3=5
📝 5/8 - 2/8 = (5-2)/8 = 3/8
分母8不變，分子相減 5-2=3
📝 4/9 + 5/9 = 9/9 = 1
分子相加等於9，9/9就是1個整體
